CASE 03 · 자동매매 · 실시간 모니터링

의뢰자의 매매 알고리즘을 그대로 자동매매로

의뢰자가 정한 매수·매도 조건을 국내장과 미국장에서 실시간으로 감시하고 자동으로 주문합니다.
보유·관심 종목의 뉴스를 모아 체결 내역과 함께 텔레그램으로 알려 줍니다.

C사 (자기자본 운용 투자법인) · 국내 주식 · 미국 주식 · 키움증권 REST · WebSocket · C# .NET · SQL Server · Telegram Bot API

다른 구축 사례

01이런 문제가 있었습니다

  • 주문 지연조건이 충족돼도 사람이 확인하고 주문하기까지 시간이 걸려 원하는 가격을 놓쳤습니다.
  • 규칙 미준수손절 가격에 도달해도 주문을 미루는 일이 반복됐습니다.
  • 야간 감시 부담미국장을 보기 위해 매일 밤 사람이 화면을 지켜야 했습니다.

  2. SIGNAL알고리즘 조건 판단
  3. RISK손절·손실 한도 검사
  4. ORDER자동 매수·매도
  5. ALERT기록 · 텔레그램 알림

의뢰자 알고리즘 구현

보유한 매매 규칙을 조건식으로 정리해 그대로 코드로 옮기고, 모의투자로 검증합니다.

실시간 모니터링

국내·미국 보유 종목, 차트, 주문 상태, 손익을 한 화면에서 봅니다.

자동 매수·매도

분할 주문과 미체결 재주문을 자동으로 처리하고, 중복 주문을 막습니다.

리스크 규칙

손절, 종목별 비중 한도, 일일 손실 한도를 전략보다 먼저 적용합니다.

관련 종목 뉴스 취합

공개 RSS·API로 보유·관심 종목 뉴스를 모아 한곳에서 확인합니다.

텔레그램 알림 · 긴급 정지

체결·손절·오류를 알림으로 받고, 허용된 계정만 전체 정지 명령을 보낼 수 있습니다.

04자주 묻는 질문

매매 전략도 만들어 주나요?

아닙니다. 의뢰자가 가진 매매 규칙을 정확하게 구현하고 검증하는 개발만 합니다. 투자 판단이나 종목 추천은 하지 않습니다.

키움증권 외 다른 증권사도 가능한가요?

한국투자증권 등 Open API를 제공하는 증권사라면 연동할 수 있습니다.

개인 투자자도 의뢰할 수 있나요?

네. 본인 명의 계좌와 본인이 정한 매매 규칙을 자동화하는 경우에 한해 개발하며, 투자 결과는 사용자 책임입니다.

매매 규칙, 그대로 자동화해 드립니다

사용 중인 증권사와 매매 규칙을 알려주시면 구현 범위를 정리해 드립니다.
