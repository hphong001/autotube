CORE TECHNOLOGY

현장의 장비, 데이터, AI를 하나로 잇는 4가지 기술

기술은 따로 떨어져 있을 때보다 연결될 때 가치가 커집니다.
네 가지 기술은 모두 같은 설계 원칙(모듈 분리, 자동 기록, 예외 상황 우선 설계)으로 만들어져 필요에 따라 조합할 수 있습니다.

반복 업무 · 영상 제작 자동화 장비 연동 · 모니터링 금융 데이터 · 자동매매 출하 검수 · MES 연동
01 · WORKFLOW AUTOMATION

반복 업무 자동화
영상 제작 자동화

여러 프로그램을 오가며 파일을 옮기고, 복사하고, 이름을 맞추는 일은 생각보다 많은 시간을 차지합니다. 반복 업무 자동화는 이런 단계를 하나의 흐름으로 묶고, 각 단계에 생성형 AI를 결합해 사람은 판단과 검수만 하도록 만듭니다.

이런 업무에 적합합니다

  • 유튜브·교육 영상처럼 정해진 형식으로 반복 제작하는 콘텐츠
  • 엑셀·문서 데이터를 받아 이미지, 음성, 보고서로 변환하는 업무
  • 여러 웹사이트·프로그램에 같은 내용을 반복 입력하는 업무

생성형 AI 연동

Gemini 이미지 생성을 API와 브라우저 자동화 두 경로로 연결하고, 캐릭터 시트 첨부로 결과물 일관성을 유지합니다.

로컬 AI 음성 · 자막

Qwen3-TTS 음성 합성과 Whisper 음성 인식을 고객 PC의 GPU에서 실행해 비용과 데이터 유출 걱정이 없습니다.

편집 도구 자동 조립

CapCut 프로젝트 파일을 직접 생성해 이미지·음성·자막 트랙을 자동 배치합니다.

브라우저 · 화면 자동화

API가 없는 웹 서비스나 프로그램도 Playwright, Windows 자동화로 반복 조작을 대신합니다.

적용 사례: 교육 콘텐츠 제작사 영상 제작 자동화

02 · EQUIPMENT INTEGRATION

이기종 장비 연동
중앙 모니터링

생산 현장에는 제조사도, 통신 방식도 다른 장비가 섞여 있습니다. 장비마다 전용 프로그램을 따로 쓰면 작업자는 화면을 오가야 하고 데이터는 어디에도 남지 않습니다. 기존 장비를 그대로 두고, 하나의 프로그램에서 제어·측정·판정·기록까지 처리하도록 연결합니다.

분류지원 통신 · 프로토콜주요 장비 예시
시리얼RS-232, RS-485, USB 가상 시리얼전원공급기, 바코드 스캐너, 저울, 컨트롤러
산업용 네트워크Modbus RTU/TCP, Mitsubishi MC ProtocolPLC, 인버터, 온습도 로거, 센서
계측기SCPI (VISA · LAN · USB · GPIB)오디오 분석기, 멀티미터, 오실로스코프
네트워크 장비TCP/UDP 소켓, HTTP REST, ZPL라벨 프린터, 산업용 카메라, 서버

검사 레시피

모델별 측정 순서와 합격 기준을 코드가 아닌 설정으로 관리해, 신모델 추가 시 개발 없이 대응합니다.

자동 기록 · 추적

모든 측정값을 시리얼 번호별로 저장하고, 네트워크가 끊겨도 로컬에 보관했다가 서버와 동기화합니다.

중앙 관제 대시보드

여러 라인의 가동 상태, 합격률, 택트타임, 장비 연결 상태를 한 화면에서 실시간으로 확인합니다.

다국어 작업 화면

해외 공장 작업자를 위해 중국어·영어·한국어 화면을 제공합니다.

적용 사례: 음향기기 제조사 계측 장비 연동 검사

03 · FINANCIAL DATA & AUTO TRADING

금융 데이터
자동매매 시스템

증권사 Open API로 국내·해외 시세를 실시간으로 받고, 사용자가 정한 매매 규칙을 정확하게 집행하는 시스템을 개발합니다. 수익을 약속하는 전략이 아니라 정해진 규칙을 감정 없이, 빠르게, 빠짐없이 실행하는 도구를 만듭니다.

증권사 API 연동

키움증권 REST·WebSocket, 한국투자증권 Open API 등으로 시세 수신, 잔고 조회, 주문을 처리합니다.

스크리너 · 차트

추세 단계, 거래량, 이동평균 등 조건 검색과 Lightweight Charts 기반 실시간 캔들 차트를 제공합니다.

리스크 관리 · 안전장치

비중 한도, 일일 손실 한도, 추적 손절, 연결 끊김 시 주문 중단, 킬 스위치를 기본 탑재합니다.

알림 · 기록

텔레그램으로 체결과 결산을 받고, 모든 주문의 발생 조건을 DB에 남겨 성과 분석에 활용합니다.

적용 사례: 투자법인 키움증권 국내·미국 자동매매

04 · INSPECTION & MES

출하 검수 · 비전 검사
MES 연동

바코드, 산업용 전자저울, 카메라를 하나의 검수 프로그램으로 묶습니다.
잘못된 제품·수량, 구성품·라벨 누락을 출하 전에 걸러내고,
결과를 사진과 함께 남겨 MES로 실시간 전송합니다.

이런 의뢰를 받습니다

  • 바코드·QR로 주문서와 출하 제품 대조, 오출고 경고
  • 산업용 전자저울 연동 중량 검사 (구성품 누락 감지)
  • 카메라로 라벨·부품 유무 검사, 검수 사진 이력 저장
  • 생산 수량 카운팅·현황판, MES·ERP 실적 전송

규칙 기반 비전 검사

정해진 위치의 라벨·부품 유무를 판별합니다. AI 학습 데이터 없이 바로 시작할 수 있습니다.

장비 연동

USB·RS-232·LAN 바코드 스캐너와 전자저울, 경광등·부저를 연동합니다.

MES · ERP 전송

REST API, DB, CSV 등 기존 시스템이 받을 수 있는 방식으로 실적을 보냅니다.

AI 검사로 확장

복잡한 외관 불량은 필요할 때 딥러닝 검사로 확장할 수 있습니다.

적용 사례: 바코드·중량·비전 출하 검수 자동화

SECURITY & DELIVERY

데이터 보안 · 납품 원칙

  • 온프레미스 우선: 생산 데이터와 매매 기록은 고객사 내부 PC·서버에 저장합니다.
  • 인증 정보 보호: API 키·토큰·DB 접속 정보는 암호화해 보관하고 화면과 로그에 노출하지 않습니다.
  • 권한 분리: 작업자·관리자 권한을 나누고 설정 변경 이력을 남깁니다.
  • NDA · 소스 제공: 요청 시 착수 전 비밀유지계약을 맺고, 계약에 따라 소스 코드를 함께 납품합니다.
DESIGN PRINCIPLES

모든 시스템에 공통으로 적용하는 설계 원칙

현장 시스템은 잘 돌아갈 때보다 문제가 생겼을 때 진가가 드러납니다.

  1. 기존 설비 유지

    장비와 프로그램을 교체하지 않고 연결하는 방식을 우선 검토해 도입 비용과 위험을 줄입니다.

  2. 예외 상황 먼저 설계

    통신 끊김, 장비 무응답, 잘못된 입력 등 예외 처리를 기능보다 먼저 설계합니다.

  3. 모든 것을 기록

    판정, 주문, 설정 변경 이력을 남겨 문제 원인을 추적하고 개선 근거로 활용합니다.

  4. 사람은 판단에 집중

    반복 작업은 자동화하되, 품질과 위험에 관한 최종 판단은 사람이 할 수 있게 설계합니다.
