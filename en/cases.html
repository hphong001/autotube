CASE 01 · EQUIPMENT INTEGRATION · MONITORING

Three measuring instruments in one test program

Audio equipment manufacturer · final test station · audio analyzer · DC power supply · barcode scanner · C# .NET · Excel · Telegram Bot API

Challenge

  • Operators switched between a separate program for each instrument on every unit.
  • Measurements were written on paper and re-typed into Excel after each shift.
  • Checking test progress required walking to the line.

Solution

  • RS-232, USB and LAN (SCPI) instruments controlled from one program.
  • Serial number, measurements and pass/fail logged to Excel automatically.
  • Live charts, data review, and Telegram alerts and remote control for authorized users.

Results

  • Paper records and re-typing eliminated
  • Test history found instantly by serial number
  • Status checked from the office or outside
  • Accumulated data used for defect trend analysis

CASE 02 · QA INSPECTION · VISION · MES

Outgoing QA inspection: barcode, weight and camera checks before release

Manufacturer · outgoing QA inspection station · barcode scanner · industrial scale · industrial camera · signal tower · MES server (REST API · DB)

Challenge

  • Wrong products or quantities were occasionally packed and shipped.
  • Boxes sometimes left with missing components or labels.
  • No record of product condition at release, and production counts entered into the MES late by hand.

Solution

  • Scanned codes compared with the order, with instant sound and screen alerts.
  • Scale integration checks weight tolerance; rule-based camera checks confirm labels and parts — no AI training data needed.
  • Photos stored per order and serial; counts and progress sent to the MES in real time.

Results

  • Wrong items and missing parts caught before release
  • Photo evidence available for customer claims
  • Production counts reflected in the MES live
  • Line progress visible from the office

CASE 03 · VIDEO PRODUCTION AUTOMATION

Video production time cut from 9 hours to 2 hours 40 minutes

Education content company · 4 YouTube channels · 3 editors · AutoTube Pro with channel-specific settings · Gemini image · Qwen3-TTS · Whisper

Challenge

  • Five separate tools for images, voice, subtitles and editing — files moved by hand and cut numbers matched manually.
  • Re-recording a voice-over took 2–3 days for a single script change.
  • Fixing auto-generated subtitles took about 90 minutes per video.

Solution

  • Excel script in, consistent character images per cut generated by AI.
  • Sentence-level AI voice on a local GPU — re-record a single cut any time.
  • Subtitles aligned to the original script, so no typos; CapCut project assembled automatically.

Results

  • Production time per video: 9h → 2.7h
  • Weekly output: 5 → 12 videos
  • Subtitle correction: 90 → 10 min
  • External voice-over cost: eliminated

CASE 04 · AUTOMATED TRADING · KOREAN BROKER API

The client's trading algorithm, automated exactly as written

Proprietary investment firm · Korean & US stocks · Kiwoom REST / WebSocket · C# .NET · SQL Server · Telegram Bot API

Challenge

  • Manual confirmation delayed orders and missed target prices.
  • Stop-loss levels were reached but orders were postponed.
  • Someone had to watch the US market every night.

Solution

  • The client's rules implemented as code and verified on a paper-trading account.
  • Split orders, re-orders and duplicate-order protection handled automatically.
  • Risk rules applied before the strategy; news, fills and errors sent to Telegram with an emergency stop.

Results

  • Signal → order accepted: 42s → 0.4s
  • Stop-loss rule execution: ~70% → 100%
  • Night-time manual monitoring: 25 → 3 hours/week
  • Returns are not disclosed; metrics show execution accuracy
