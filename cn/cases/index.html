IMPLEMENTATION CASES

我们设计并交付过的系统

这些项目是我们在韩国提供技术支持的基础——设备通讯、检测系统以及与工厂系统的对接。应客户要求，案例以行业名称展示。

CASE 01 · 设备集成 · 监控

3台测量仪器，一个检测程序

音响设备制造商 · 出货检测工位 · 音频分析仪 · 直流电源 · 条码扫描枪 · RS-232 / USB / LAN (SCPI) · C# .NET · Excel · Telegram Bot API

面临的问题

  • 每检测一台产品，都要在各仪器软件间来回切换。
  • 测量数据先写在纸上，交班后再录入Excel。
  • 想了解检测进度，必须有人到产线现场查看。

我们做了什么

  • 通过RS-232、USB、LAN（SCPI）在一个程序中控制全部仪器：扫码、测量、判定、记录。
  • 序列号、测量值与判定结果自动保存到Excel。
  • 实时图表与回放，可调取历史数据分析不良分布。
  • 通过Telegram推送合格率、不良与设备异常；远程指令仅限授权账号执行。

结果

  • 不再需要手写记录和重复录入Excel。
  • 凭序列号即可查到检测记录，用于回复客户咨询。
  • 在办公室或厂外也能掌握检测情况。
  • 积累的数据用于分析不良趋势。
CASE 02 · 出货检测 · 视觉 · MES

出货检测：放行前完成条码、重量与相机检查

制造企业出货线 · 检测工位 · 条码扫描枪 · 工业电子秤 · 工业相机 · 警示灯塔 · MES服务器 (REST API · 数据库)

面临的问题

  • 偶尔出现产品或数量装错后发出的情况。
  • 有时箱内缺少配件或标签就出货了。
  • 出货时没有产品状态的记录，生产数量靠手工汇总，录入MES滞后。

我们做了什么

  • 扫描条码比对订单，不一致时立即声光提示。
  • 对接电子秤，按标准重量与允许误差检查缺件。
  • 基于规则的相机检测标签与部件有无，
    无需AI训练数据。
  • 按订单与序列号保存照片；
    数量与进度实时上传MES。

结果

  • 错发与缺件在出货前被发现。
  • 出货时的照片可作为客户索赔时的依据。
  • 生产数量无需手工汇总即可反映到MES。
  • 管理人员在办公室即可查看产线进度。
